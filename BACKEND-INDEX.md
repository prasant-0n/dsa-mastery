## Backend Lab Standard

Each lab should document:

1. Problem
2. Constraints
3. Naive design
4. Algorithm/data-structure choice
5. Correctness
6. Complexity
7. Memory behavior
8. Concurrency considerations
9. Failure modes
10. Production trade-offs
11. Tests
12. Benchmark observations
