# AI Algorithm Index

Connect DSA to modern AI engineering systems.

| AI System / Problem | Core Algorithms / Structures |
|---|---|
| Similarity Search | Distance functions, vector operations |
| Nearest Neighbor | Exact search, tree-based search |
| Approximate Nearest Neighbor | HNSW, LSH, tree-based indexing |
| Vector Indexing | Graphs, hierarchical structures |
| Top-K Retrieval | Heap / selection algorithms |
| Ranking | Sorting, heaps, scoring functions |
| Reranking | Candidate generation + scoring |
| Hybrid Search | Lexical indexing + vector retrieval |
| Metadata Filtering | Hashing, indexes, set operations |
| RAG Retrieval | Chunking + indexing + ANN + Top-K |
| Recommendation Retrieval | Candidate generation + ranking |
| Deduplication | Hashing / similarity checks |

## AI Lab Standard

Each lab should document:

1. Mathematical intuition where required
2. Data representation
3. Algorithm
4. Complexity
5. Recall/latency trade-offs where applicable
6. Memory considerations
7. Failure modes
8. Scaling considerations
9. Backend integration point
10. Practical retrieval/application example
