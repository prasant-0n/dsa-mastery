# Phase 00 — Programming Readiness

> Build enough programming fluency that JavaScript syntax never becomes the bottleneck while learning DSA.

## Objective

Before studying algorithms seriously, establish a reliable foundation in the parts of JavaScript that DSA depends on.

## Learning Rule

For each chapter:

1. Understand the concept.
2. Trace small examples by hand.
3. Write the code without copying.
4. Predict the output before running it.
5. Identify common mistakes.
6. Complete the exercises.
7. Revisit the chapter during revision.

## Exit Criteria

You are ready for Phase 01 when you can comfortably:

- write functions without syntax lookup;
- traverse and modify arrays;
- work with objects, `Map`, and `Set`;
- reason about references and mutation;
- write loops and nested loops;
- explain basic recursion and the call stack;
- read unfamiliar JavaScript without getting blocked by syntax.

## Important

This phase is **not** intended to reteach all of JavaScript. It is a DSA readiness checkpoint. Topics you already know should be reviewed quickly; weak areas should be practiced until they stop interfering with algorithmic reasoning.
