# Problem-Solving Index

This index is for problems selected to build reasoning, not merely solution counts.

## Required Record

Every problem should capture:

- Problem statement
- Constraints
- Observations
- Brute force
- Bottleneck
- Optimization insight
- Chosen data structure/pattern
- Correctness reasoning
- JavaScript implementation
- Time complexity
- Space complexity
- Edge cases
- Mistakes
- Variation
- Interview explanation

## Problem Progression

### Level 0 — Mechanical

Traversal, basic counting, direct simulation, simple array/string operations.

### Level 1 — Easy

Single-pattern problems with limited state.

### Level 2 — Easy+

Problems requiring one non-obvious observation or data structure.

### Level 3 — Medium

Pattern recognition plus implementation discipline.

### Level 4 — Medium+

Multiple concepts, stronger constraints, or less obvious derivation.

### Level 5 — Hard

Complex state, multiple interacting techniques, or advanced algorithms.

## Independence Score

Use this simple score after each attempt:

- **0** — Could not start
- **1** — Needed complete solution
- **2** — Solved with hints
- **3** — Solved independently
- **4** — Solved independently and explained clearly
- **5** — Solved variation without help
